# OptiSolar EPC Calculator

A Russian-language proposal calculator for solar and battery energy storage projects. This repository contains the static Telegram Mini App frontend.

To run in Telegram, publish the root `index.html` over HTTPS, then connect its URL to a Mini App in BotFather. See [TELEGRAM_MINI_APP.md](TELEGRAM_MINI_APP.md).

Project prices and ratebook values are included in client-side JavaScript for this prototype.
